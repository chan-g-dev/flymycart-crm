# Application review - 25 September 2026

## Decision

Local checks and the compiled production build pass the verification below. **Live production sign-off remains pending:** the configured Render API and the Vercel API proxy repeatedly timed out from this environment. The backend URL was confirmed by the owner. The exact hosting failure could not be diagnosed without Render service/deployment logs; these timeouts alone do not establish the root cause.

Changes are saved in the working tree. Nothing was committed, pushed, or deployed. Existing application changes were preserved.

## Fixes completed during this review

- Fixed attendance authorization: an explicitly denied `attendance.manage` permission no longer grants staff-wide reads or punches on behalf of another staff member.
- Fixed attendance presentation: use API work-duration/delay fields, remove sample staff and invented duration fallbacks, show load errors and retry, discard stale filtered responses, and make monthly summaries request the selected month. Quick punches use the current IST day/time. Management controls respect permissions.
- Preserve entity and DDP when converting accepted customer bookings unless the operator explicitly overrides them.
- Added database-backed KYC pagination, global search and date filters. Records beyond the first 100 are reachable, results load in bounded pages, and document selection resets when the filter/page changes. ZIP actions clearly apply to selected records or the current page. The query was verified against SQLite and PostgreSQL.
- Fixed negative Excel monetary values being exported as text while retaining protection for formula-like text values.
- Removed a duplicate report API method, fixed React state synchronization and unstable memo inputs, and removed unused code that caused the strict lint check to fail.
- Updated the isolated workflow script's role assertions to match the new manager permissions already present in this application's changes.
